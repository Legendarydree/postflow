Local desktop application

Postflow

Postflow is a local desktop application designed to help users manage content workflows and connect supported social platforms through secure OAuth authorization.

Local-first

The application runs locally on the user's computer and exposes its interface through a local address.

OAuth integrations

Supported platforms are connected using their official authorization flows and permissions selected by the user.

User control

Users choose which accounts to connect and which authorized features to use.

Desktop callback

Postflow uses a local loopback callback for desktop OAuth flows: http://127.0.0.1:8765/oauth/tiktok/callback

About this website
