# Postflow

Official public page for Postflow.

Postflow is a local desktop application for managing content workflows and connecting supported social platforms through OAuth.

## GitHub Pages

After enabling GitHub Pages for the `main` branch and `/ (root)` folder, the site should be available at:

`https://legendarydree.github.io/postflow/`

## OAuth callback

The TikTok desktop callback remains local:

`http://127.0.0.1:8765/oauth/tiktok/callback`

Do not publish Client Keys, Client Secrets, access tokens, refresh tokens, or other credentials in this repository.
